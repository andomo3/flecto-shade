# Presentation checklists

The playbook's win checklist, cut to what applies to a hardware booth with no network.
Dropped on purpose: the live URL, the venue Wi-Fi test, slides and projectors, demo accounts, and API keys, because this project has none of them.

## Rehearsal, before judging

- [ ] The 60 second script said out loud, with a timer, three times.
- [ ] One run recorded on a phone, then filler cut until it is ten seconds under.
- [ ] One run with the laptop unplugged from the board, using only the recorded run and the backup clip.
- [ ] One run with replay mode on, saying the honest sentence.
- [ ] One run to someone outside the team, the playbook's "mom test": can they say what it does?
- [ ] The opening line and the closing line memorised by the speaker and by the backup speaker.
- [ ] The fifteen second version ready, for a judge who is walking past: "A bus stop roof with no hinges that bends into shade when the sun hits it. Press play."
- [ ] Scored with the 30 point self assessment in the `hackathon-pitch` skill's win checklist.
      Under 21, practise more, and under 16, fix the demo's reliability before polishing anything.

## One hour before judging

Table:

- [ ] The model faces the aisle, the laptop sits behind and above it, and the judge's hand can reach both the Play button and the light sensor.
- [ ] A dark backdrop stands behind the model so the LED reads as the sun.
- [ ] The four placards stand where they can be read from a metre, and the QR has been tested with two phones.
- [ ] A spare leaf lies on the table to be bent by hand.
- [ ] Every cable is taped down, and the servo's supply is charged or plugged in.
- [ ] The override button is within the speaker's reach.

Laptop:

- [ ] Wi-Fi off, and the app still runs.
- [ ] The backup clip is on the desktop and on a phone, and plays.
- [ ] This morning's recorded run is committed and replays.
- [ ] Five screenshots are saved locally.
- [ ] Notifications off, sleep and the screensaver off, the charger connected, the browser full screen at 100 percent zoom.
- [ ] "Reset the day" works and takes under five seconds.

Thresholds:

- [ ] The light threshold was set in this room, under this room's lights, within the last hour.
- [ ] Ten cycles run back to back without a miss, or replay mode is on and the banner says so.

People:

- [ ] Everyone has eaten and had water.
- [ ] One speaker drives, and everyone knows which questions are theirs.
- [ ] The backup speaker can give the 60 second version.
- [ ] Everyone knows the recovery lines in `script.md`.

## During each visit

| Time | Do |
|---|---|
| Before speaking | Eye contact, a breath, no "hi, we are" |
| 0:00 | "Picture Rosa." The opening line, from memory |
| 0:25 | "Would you press play?" The judge touches it |
| 0:40 | Stop talking while the leaves bend. Point at the leaves, then at the bars |
| 0:50 | "Put your hand over that sensor." |
| 1:15 | The number, and what was not measured |
| 1:25 | The closing line, then silence. Let the judge speak first |
| Questions | Thirty seconds each, the builder answers, end with "thank you" |

If something fails, switch once, apologise once, and keep telling the story.

## Between visits, thirty seconds

- [ ] Reset the day.
- [ ] Leaves resting, LED off, the spare leaf back in its place.
- [ ] Glance at the supply, the cables, and the sensor position.
- [ ] Water.

## After judging

- [ ] Thank each judge, by name if it was offered.
- [ ] Write down every question that was asked, while it is fresh, in `questions.md`.
- [ ] Push the final state of the event repo, with the README, the video, and the numbers.
- [ ] Photograph the table, the placards, and the team.
- [ ] Note what to do differently, the same day.
