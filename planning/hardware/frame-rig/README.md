# Frame and rig

Owner: the structure and rig role.

What goes here:

- `linkage.md`, the dimensioned interface between the leaves and the frame: backbone mount points, the pull wire or rigid link, servo horn, travel angle.
  This is a hotspot file, the structure owner writes it and the mechanism owner signs it before either side prints.
- The foam board bus stop frame, the servo box, and the LED sun mount, as CAD links or dimensioned photos.
- The LED sun mount and the photoresistor position, photographed, so the line of sight survives a rebuild.
- Milestone exports under `../exports/` named `frame-<YYYY-MM-DD>.stl` or `.step`.
