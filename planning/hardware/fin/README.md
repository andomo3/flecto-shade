# Leaves

Owner: the mechanism role.

What goes here:

- Backbone and lamina CAD links, with the settings that worked: backbone and lamina thickness, the resting curve, infill, nozzle, filament.
- The variant results, which thickness combination buckled cleanly in the intended direction, as a short table with the time.
- Milestone exports under `../exports/` named `leaf-<YYYY-MM-DD>.stl`, never native CAD files here.
- The foam board fallback: what was cut, from what, so anyone can remake it.

The backbone mount points and the link to the servo are fixed by `../frame-rig/linkage.md`.
Do not change them here, ask the structure owner.
