# Checklist, the table version

`planning/pitch/checklist.md` with the software items made concrete.
Tick these on the day.

## The laptop, once

- [ ] `cd software && ../.venv/Scripts/python -m pytest tests -q` exits 0.
- [ ] `python -m canopy serve --source fixture` serves the page with the network off.
- [ ] `python -m canopy serve --source fake` runs the whole day and reaches the result card.
- [ ] `python -m canopy serve --source serial --port-name <port> --record` writes a file under `software/fixtures/`.
- [ ] That recorded file replays with `--source fixture --fixture software/fixtures/run-....csv`.
- [ ] Wi-Fi off, notifications off, sleep and screensaver off, charger in, browser full screen at 100 percent zoom.
- [ ] The backup clip is on the desktop and on a phone, and plays.
- [ ] Five screenshots saved locally, including the hero frame: midday, leaves bent, the two bars apart.

## Rehearsal

- [ ] The 60 second script said out loud with a timer, three times.
- [ ] One run with the board unplugged, using the recorded run only.
- [ ] One run with replay mode on, saying the honest sentence while the banner shows.
- [ ] One run to someone outside the team: can they say what it does?
- [ ] The opening and closing lines memorised by the speaker and the backup speaker.
- [ ] The fifteen second version ready.

## One hour before judging

- [ ] The model faces the aisle, the laptop behind and above it, Play and the light sensor both within the judge's reach.
- [ ] A dark backdrop behind the model so the LED reads as the sun.
- [ ] The four placards stand where they can be read from a metre, and the QR is tested with two phones.
- [ ] A spare leaf lies on the table to be bent by hand.
- [ ] Cables taped, servo supply charged or plugged in.
- [ ] The light threshold set in this room, under this room's lights, within the last hour.
- [ ] Ten cycles back to back without a miss, or replay mode is on and the banner says so.
- [ ] "Reset the day" works and takes under five seconds.
- [ ] Card 1's numbers match the result card exactly.
- [ ] Everyone has eaten and had water.

## Between visits, thirty seconds

- [ ] Reset the day, or press R.
- [ ] Leaves resting, LED off, the spare leaf back in its place.
- [ ] Glance at the supply, the cables, and the sensor position.
- [ ] Water.

## After judging

- [ ] Thank each judge.
- [ ] Write down every question asked, while it is fresh.
- [ ] Push the final state of the repo, with the README, the video, and the numbers.
- [ ] Photograph the table, the placards, and the team.
